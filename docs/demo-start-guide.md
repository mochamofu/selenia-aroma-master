# デモ起動ガイド

このページは、エンジニアではない人が、アプリの画面を開いて操作を試すための案内です。

## 1. いちばん簡単な方法

下のリンクを押してください。

**[脳波アロマ管理カルテを開く](https://aroma-records-pwa.vercel.app/operator)**

画面が開けば、アプリは起動できています。ログイン画面が表示された場合は、公開環境の認証設定が有効になっています。デモ用のログイン情報が必要な場合は、管理者または開発担当者に確認してください。

## 2. まず試す操作

画面を開いたら、次の順番で触ってください。

1. 左側の「顧客階層」から顧客を1人選ぶ
2. 「過去の診断・制作履歴」から日付の違う履歴を選ぶ
3. 右側の脳波画像が履歴に合わせて切り替わることを確認する
4. 「画像を拡大」で画像を大きく表示する
5. 「香り制作記録」で完成量を5mLまたは10mLに切り替える
6. 「表示: μL」ボタンでμLとmLの表示を切り替える
7. 配合材料の数値が、選択した完成量に応じて変わることを確認する
8. 中央下部の「ヒアリングシート回答履歴」で、選択中の制作履歴に対応した回答を確認する

## 3. スマートフォン実機で試す

スマートフォンのブラウザで、次のURLを開くだけです。

`https://aroma-records-pwa.vercel.app/operator`

PCから実機に近い表示を確認する場合は、Chromeなどの開発者ツールでスマートフォン表示を選び、幅390px・高さ844px程度にします。リポジトリにはそのサイズで撮った画面キャプチャもあります。

![スマートフォン表示のカルテ画面](../output/screenshots/operator-mobile-390x844.png)

## 4. 購入者向け画面を試す

**購入者向け画面はこのリポジトリには含まれません。**
利用者（購入者）向けアプリは別リポジトリ `mochamofu/selenia-aroma-user` が担当します。

購入者向け画面では、ダッシュボード、香りの一覧、香りの詳細、再購入、気分別検索、ベースブレンド、精油図鑑、プロフィールを確認できます。

## 5. ローカルで起動する場合

開発用PCで確認する場合だけ、次の手順を使います。

```powershell
npm install
npm run dev
```

その後、ブラウザで次を開きます。

- `http://localhost:3000/operator`: 事業者向けカルテ
- `http://localhost:3000/dashboard`: 購入者向け画面
- `http://localhost:3000/login`: ログイン画面

ローカル起動は、黒い画面にコマンドを入力する必要があります。単に画面を試すだけなら、上の公開URLを使う方が簡単です。

## 6. このデモで確認できる範囲

- 顧客8名のデモデータ
- 顧客ごとの複数回の制作履歴
- 脳波画像と制作履歴の切り替え
- 画像タイトル、画像メモ、拡大確認
- 5mL / 10mLの完成量変更
- μL / mL表示切り替え
- 配合量の自動計算
- ヒアリング回答と禁忌・注意事項
- 精油図鑑とベースブレンド図鑑

## 7. 注意点

これは現行デモです。現在は画面確認用のモックデータとブラウザ内stateが中心で、正式な顧客情報保存、脳波画像の永続保存、認証・権限管理、測定機器からの自動データ受信は本番化の作業項目です。実顧客情報や実際の脳波画像は入力しないでください。
