# Selenia Aroma ベースブレンドレシピDB

作成日: 2026年7月7日  
用途: オイル作成事業者向けカルテアプリの設計資料  
公開区分: 内部資料

## 重要な取り扱い

この資料には、ベースブレンドの配合比率を含む。

顧客向けアプリでは、配合比率は公開しない。顧客向けに表示してよい情報は以下のみとする。

- ベースブレンド番号
- 仮名
- 含まれるオイルの種類
- 目的・効能カテゴリ

配合比率は、オイル作成事業者側のカルテアプリ、管理者画面、または内部DBのみで扱う。

## DB項目案

### base_blends

公開可能なベースブレンド情報。

| 項目 | 型 | 説明 |
|---|---|---|
| id | string | 内部ID |
| code | string | ブレンド番号 |
| name | string | 仮名 |
| public_ingredients | string[] | 公開可能な構成オイル |
| benefits | string[] | 目的・効能カテゴリ |
| description | text | 公開説明 |
| color | string | UI表示色 |

### base_blend_private_recipes

事業者・管理者のみが扱う内部レシピ。

| 項目 | 型 | 説明 |
|---|---|---|
| id | string | 内部ID |
| base_blend_id | string | base_blendsへの参照 |
| internal_ratio | string | 配合比率 |
| private_note | text | 作成者向けメモ |
| created_at | datetime | 作成日時 |

## カルテアプリでの利用想定

オイル作成事業者側のカルテアプリでは、以下を1件の制作カルテとして管理する。

| 項目 | 説明 |
|---|---|
| customer_id | 顧客ID |
| aroma_record_id | 顧客向けアプリの制作記録ID |
| blend_lot_number | 投資番号・ロット番号 |
| base_blend_id | 使用したベースブレンド |
| base_blend_volume_ml | 使用したベースブレンド量 |
| added_oils | 追加したオイル |
| added_oil_drops | 追加滴数 |
| brainwave_profile_id | 脳波データ連携ID |
| maker_note | 作成者向け内部メモ |
| public_note | 顧客に公開してよい説明 |

## 表示ルール

### 顧客向けアプリ

表示する:

- ベースブレンド名
- ベースブレンド使用量
- 含まれるオイルの種類
- 追加したオイル
- 追加滴数
- ブレンドメモ
- 使用方法
- 注意事項

表示しない:

- ベースブレンド配合比率
- 内部レシピ
- 作成者向けメモ

### 事業者向けカルテアプリ

表示する:

- ベースブレンド配合比率
- 実際の作成メモ
- ロット番号
- 脳波データ
- 顧客別履歴
- 再作成に必要な内部情報
